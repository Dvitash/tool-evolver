# Tool Evolver V1.0.0 Release Notes

**Release Tag**: `v1.0.0`  
**Release Date**: August 17, 2026  
**Status**: General Availability (GA)

Tool Evolver V1.0.0 marks the first official production-ready release of the autonomous, privacy-safe developer tool evolution platform. This milestone brings full end-to-end support for automated tool discovery, synthesis, sandboxed verification, canary deployment, and seamless integration with Claude Code, Codex CLI, and Oh My Pi.

---

## Highlights & Key Features

### 🚀 Autonomous Tool Evolution Engine
- **Session Observation**: Local userspace tailing of AI coding sessions with real-time detection of repetitive workflows and opportunity clustering.
- **AST-Guided Synthesis**: Autonomous generation of robust, type-safe TypeScript tool candidates tailored to detected workspace patterns.
- **Historical Replay Benchmarking**: Automated execution of synthesized candidates against historical test fixtures to score correctness and performance before deployment.

### 🛡️ Hardened Sandbox & Capability Envelope
- **Least-Privilege Sandboxing**: Strict isolation using Deno/cgroup sub-process execution models with CPU (1.0 core), memory (512MB), and execution time (30s) hard caps.
- **Zero Raw Data Exfiltration**: User prompts, thoughts, and proprietary source code remain strictly local. Only sanitized, privacy-safe metadata is processed.
- **Mediated Secret Injection**: Direct reading of credentials and sensitive dotfiles (`.env`, `.ssh`, `.aws`) is blocked by default; secrets are injected securely as environment variables.

### 🔄 Multi-Harness MCP Integration
- **Invariant Meta-Tools**: Exposes `search_tools`, `get_tool_schema`, `invoke_tool`, and `manage_tools` over Model Context Protocol (MCP) via Server-Sent Events (SSE).
- **Zero-Restart Live Reloading**: Newly promoted or updated tools are broadcast via SSE `notifications/tools/list_changed` for instant availability in active coding sessions.
- **Automated Configuration**: One-command initialization (`npx tool-evolver init`) automatically configures Claude Code, Codex CLI, and Oh My Pi.

### ⚡ Autonomous Canary Promotion & Rollback
- **Gradual Traffic Splitting**: Newly synthesized tools undergo canary evaluation with configurable traffic percentages (default: 10%).
- **Sub-Second Rollbacks**: Automated detection of error rate spikes, latency regressions, or capability violations triggers instant rollback to last known good versions.

---

## Getting Started with V1.0.0

Install and initialize in a single command:

```bash
npx tool-evolver init
```

Verify service status:

```bash
tool-evolver status
```

---

## Upgrade & Compatibility Notes

- V1.0.0 establishes the baseline stable contract for all `@tool-evolver/*` packages.
- Supported on Linux (x64/arm64), macOS (Apple Silicon/Intel), and WSL2.
- Requires Node.js `>= 22.0.0`.
